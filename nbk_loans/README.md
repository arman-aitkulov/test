# Кредиты банковского сектора по регионам (Нацбанк РК)

Streamlit-дашборд: выбираете месяц — получаете bar chart с суммой кредитов по регионам Казахстана.

Данные берутся напрямую с сайта Нацбанка — файл «Кредиты банковского сектора в региональном разрезе»
из раздела [Кредиты банковского сектора экономике (аналитическое представление)](https://nationalbank.kz/ru/news/banking-sector-loans-to-economy-analytics/rubrics/2602).
Приложение само находит страницы всех доступных лет (сейчас 2022–2026) и скачивает xlsx.

Показатели (листы файла):
- **Выдано** — объём кредитов, выданных за месяц;
- **Остатки** — остаток задолженности на 1-е число месяца;
- **Просрочка** — просроченная задолженность на 1-е число месяца.

Суммы в файле — млн тенге, на графике — млрд тенге.

## Запуск

```bash
cd nbk_loans
pip install -r requirements.txt
streamlit run app.py
```

Данные кешируются на 12 часов; кнопка «Обновить данные» в боковой панели сбрасывает кеш.

## Файлы
- `nbk.py` — поиск файлов на сайте и парсинг Excel в таблицу `sheet, region, period, value`;
- `app.py` — интерфейс Streamlit.

Примечание: до середины 2022 года области Абай, Жетысу и Улытау в статистике объединены с
Восточно-Казахстанской, Алматинской и Карагандинской областями.
